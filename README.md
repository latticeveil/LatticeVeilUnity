# LatticeVeil Unity Edition

LatticeVeil Unity Edition is the modern rebuild of LatticeVeil built in Unity.

This is the primary development repository. Releases are tagged here and the launcher uses the release name and tag for version display.

## Release Naming Convention
- Tag: {bundleVersion} (e.g. 1.0)  
- Name: V{version} - {Codename} (e.g. V1.0 - Veilwalker Survival)
